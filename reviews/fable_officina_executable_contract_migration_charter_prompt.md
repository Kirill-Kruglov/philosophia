## Architectural objective

that preserves signed scientific and author choices while eliminating manual
generation drift.

The charter must require these invariants:

1. Exactly one authoritative representation for every operative fact.
2. Finite state machines are pure executable functions, not prose tables.
3. Closed artifact schemas are executable validators with canonical JSON.
4. Markdown is generated documentation and carries no independent authority.
5. Versions, paths, cardinalities, hashes and manifests are derived, never
   hand-copied into multiple live surfaces.
6. Historical generations are Git/archive evidence, never members of the live
   operative contract and never inputs to current cardinality.
7. Verification compares generated bytes to source, never source to manually
   repeated testimony about itself.
8. A bounded complexity budget and a mandatory redesign threshold prevent a new
   repair loop.

Stay compatible with the repository's Python 3.11+ and minimal dependencies.

external schema framework is installed. Decide whether stdlib executable Python
plus canonical JSON is sufficient or whether one narrowly justified dev
