# Roadmap from recovered Stage B to the Philosophia claim

## 1. Scientific target

The next primary claim is Stage R only:

> In one frozen MINIMO theorem population and learner class, recipient-state-
> matched task selection reduces held-out entered MCTS work relative to a
> reciprocal state-matched donated selection condition, by more than a
> prospectively chosen practically relevant margin.

This is a bounded causal claim about reciprocal own-state selection. It is not a
claim that self-generated verified learning is novel in general, that the
learner is generally intelligent, or that Stage-B engineering fixtures are
scientific observations.

Truthful-history and representation-transfer questions are removed from the
current claim. They may become a separate Stage-H contract only if Stage R is
positive, and that successor contract must be frozen before Stage-R outcomes are
unsealed to its designers.

## 2. Gate R0 — durable recovery

Required closure:

1. Preserve the exact accepted L2 objects and their hashes.

   sources without rerunning the frozen selector.
3. Verify both patch routes in disposable worktrees.
4. Commit the checkpoint before further contract or implementation work.

The unaccepted L3 draft remains archival and cannot silently become authority.

## 3. Gate R1 — one bounded scientific-contract repair

Produce `PHILOSOPHIA_MINIMUM_CAUSAL_CONTRACT_R_V2` by applying only the findings
already enumerated in `TASK_SCIENTIFIC-CONTRACT_REVIEW_OPUS5.md`:

1. Remove Stage H from the active claim and outcome table.
2. Choose before implementation a practical margin `delta > 0`, interval
   procedure, independent block count and decision rule.
3. Define `R_BOUNDED_NEGATIVE` by the upper interval bound lying below `delta`;
   failure to reject a positive effect is not a negative terminal.
4. Import permanent exclusions and prospective-integrity controls.
5. Specify how capped work and censoring are analysed; retain uncapped/censoring
   diagnostics as companions that cannot replace the primary endpoint.
6. Name the residual confound between recipient state and selector score.
7. Add only the reservoir-local theorem/skeleton identity needed to make the
   held-out split real.
8. Time-box the minimum L3 projection and L4 compile/replay obligations.

Review budget: one authoring pass and one targeted confirmation. The confirmer
checks only these eight repairs and cannot open a new architecture review.
Unresolved disagreement is an author decision recorded explicitly.

## 4. Gate R2 — minimum executable slice

Implement only what Stage R needs:

- the recovered L0-L2 generator/checker boundary;
- a projection-only identity layer sufficient for disjoint reservoir and
  held-out membership;
- minimum semantic compile plus fresh replay;
- a repaired-from-scratch Stage-A-compatible learner instance;
- twin-state snapshotting;
- recipient-state and reciprocal-donor selectors;
- entered-work instrumentation and a sealed analysis record.

No general identity framework, broad compiler, Stage H machinery or scientific
root is justified at this gate. If minimum L4 compile/replay cannot be made
correct inside the registered time/resource ceiling, the MINIMO route closes and
returns to the idea gate.

## 5. Gate R3 — outcome-blind qualification and freeze

Before any treatment result exists:

1. Freeze theorem reservoir, held-out panel, exclusions and identity rules.
2. Freeze learner initialization, twin-state construction and reciprocal pairing.
3. Freeze selector features and show that a statement-only surface control does
   not explain the selector signal.
4. Freeze `delta`, sample size, strata, randomization, work cap, censoring rule,
   interval computation and all terminal thresholds.
5. Freeze keys, seeds, software hashes, compute envelope and analysis script.
6. Run only outcome-blind integrity tests: replay, leakage, aliasing, split
   disjointness, state equality and accounting conservation.

Any change after this freeze either follows a predeclared invalid-run rule or
creates a new experiment version. It cannot be described as repair of the same
experiment after seeing its answer.

## 6. Gate R4 — one Stage-R execution

The independent unit is the frozen reciprocal block, not a theorem, search
attempt or seed-level row. Both conditions start from matched recipient states;
the treatment difference is the registered source of selected tasks.

Run once under the frozen compute envelope and emit an immutable result bundle
containing raw block records, exclusions, diagnostics, environment hashes and
the predeclared analysis output.

## 7. Terminal interpretation

- `R_POSITIVE`: the lower interval bound for the registered contrast exceeds
  `delta`. This verifies the bounded Stage-R claim in this cell and permits
  authoring, but not running, a separate Stage-H contract.
- `R_BOUNDED_NEGATIVE`: the upper interval bound is below `delta`. This
  falsifies a practically useful own-state selection effect in the registered
  cell and closes this route.
- `R_INFORMATIVE_BOUNDARY`: the interval contains `delta`. The experiment is
  informative but does not verify or falsify the bounded claim. Only a
  prospectively allowed extension may follow.
- `R_INVALID`: a frozen integrity condition failed. No treatment conclusion is
  reported; rerun authority exists only if the contract named that failure and
  remedy in advance.

## 8. Review-loop limit

Each gate has one artifact, one acceptance criterion and one decision owner.

- Scientific contract: one general review already completed; one bounded repair
  confirmation remains.
- Code: one line-by-line implementation review; at most one bounded repair and
  targeted confirmation.
- Frozen experiment: integrity confirmation only, with no redesign suggestions.
- Results: analysis against the frozen decision table, not a new design review.

A finding blocks a gate only if it can change typing, randomization, treatment
contrast, independent unit, endpoint, leakage status, terminal classification or
reproducibility. Style, hypothetical future generality and unclaimed extensions
do not reopen a closed gate.
