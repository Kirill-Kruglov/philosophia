## Question (OUTLINE Slot 4c / 4b, made concrete by `world.py`)

In this world a word is an R/L walk; its element is `fold = displacement mod n`
(`displacement = #R − #L`). Two facts have different epistemic status FOR THE
LEARNER:

- **displacement** is a *language-invariant*: it is what stays fixed across the
  mind's own rearrangements of its moves. The mind can generate arbitrarily many
  different words (roads) at a fixed displacement WITHOUT the oracle
  (`unrank_word` over R/L arrangements + admissible paddings). Manufactured,
  oracle-free contact.
- **the modulus n** is a *wall of the world*: `d ≡ d+n` cannot be discovered by
  self-resampling (which never changes displacement). The model input carries no
  modulus token, so n must be learned from oracle-labeled contact.

Prior result (DIAG_04 / REPRPROBE_07): destination-credit (labeled pair-equality
CE) on even maximal curated contact MEMORIZES pairs and induces NO linearly
readable element representation for novel words (residue probe 5.24% vs 1.52%
chance) → fails the held-out floor.

**Question:** does self-manufactured displacement-experience (oracle-free
path-credit) make a *scarce* oracle budget reach held-out floor generalization,
where destination-only at the same oracle budget memorizes? And, mechanistically,
does path-credit induce a displacement representation at all?

## The path-credit signal (oracle-free; NOT answer-injection)

Only the STRUCTURAL EQUIVALENCE "these roads reach the same place" is supplied,
generated by the learner rearranging its own moves. The residue/displacement
VALUE is never given as a target.

- Sample a displacement d in range. Generate m distinct roads (words) at
  displacement d via `unrank_word` over R/L arrangements + admissible paddings.
- Objective: pull together the per-word representations r(w) of same-d roads,
  push apart different-d roads (invariance/contrastive, e.g. InfoNCE on r(w);
  r(w) = the pre-head pooled activation used in REPRPROBE_07). No d label, no
  oracle call. Sol/Opus to confirm no oracle leak and that the loss cannot see d
  as a target.

Note the ceiling this signal has BY CONSTRUCTION: it can only teach invariance to
exact displacement, not the mod-n wrap. So path-only is EXPECTED to fail the
mod-n panel — that is a feature (it isolates the world-wall), not a bug.

## Arms (matched on ORACLE budget K; path additionally uses free self-contact)

- **D (destination-only):** K oracle-labeled pairs → equality CE. (= DIAG_04-style
  baseline; expected: memorize, floor None.)
- **P0 (path-only, 0 oracle):** self-resampled displacement-invariance only.
  Purpose = mechanism (Q1): does it induce a displacement representation?
  Expected: displacement readable, mod-n panel still fails.
- **P+ (path-then-destination):** P0 representation, then the SAME K oracle-labeled
  pairs as D for the wrap. Purpose = payoff (Q2): does manufactured
  displacement-experience let the scarce K generalize?

Pick K deliberately SCARCE (well below saturation; e.g. a small fraction of the
budget) so "experience shortens the next work" is testable. Report K explicitly.
2 seeds per arm minimum (dev); more only if a result sits near a threshold.

## Metrics

- Primary: held-out panel `first_persistent_step` + per-stratum at each checkpoint
  (the frozen floor), per arm.
- Mechanism (read-only linear probes, frozen activations, no backprop):
  DISPLACEMENT linear-probe accuracy (does path induce displacement?) and RESIDUE
  linear-probe accuracy (does the combined learn the modulus?), on novel words.
- Train-vs-panel separation strip (memorization vs generalization).

## Kill conditions (registered before running)

- **Q1 kill:** P0 displacement-probe ≈ chance → self-resampling manufactures no
  derived structure in this world (thesis dead here); publish the negative.
- **Q2 kill:** P+ ≤ D on the held-out floor at matched oracle budget K → 
  manufactured experience does not shorten the next work (Slot 4c/4b negative);
  publish the negative.
- If P+ clears the floor where D does not, at matched K, with the displacement
  probe rising under path: that is the positive candidate (still dev,
  non-citable; a confirmatory version would be a separate signed run).
