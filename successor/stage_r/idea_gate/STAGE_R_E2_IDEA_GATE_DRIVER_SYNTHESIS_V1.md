## 2. Fixed decision rule

The launch packet required all three conditions:

1. identifiable and non-tautological construction;
2. a right-sized scientific residue worth measuring;
3. a decisive disposable measurement within eight focused engineering hours,
   before a scientific harness exists.

Failure of any one condition required `STOP_STAGE_R_E2_BEFORE_BUILD`. The hour
ceiling and conjunction were fixed before the three answers existed.

## 3. Evidence synthesis

### A — conditional paper identifiability: pass for purposes of this decision

Task A supplied a semiautomaton entry-coverage candidate with non-commuting
primitives, public-only self-uncertainty selection, exact twins, a reciprocal
four-branch contrast and held-out ordered-pair disjointness. It also supplied
zero/positive/negative qualitative parameter regimes.

The pass is conditional and fragile. A point mass on perfectly aligned demand
makes the positive result analytic; the admissible family must contain
prospectively fixed decoy/alignment variation. Seed twins may also have too
little error or batch discordance to host the estimand. Composition is only a
carrier property, and deterministic traces support no proof-diversity claim.

Those caveats do not need another paper review here. Even granting Task A's
positive verdict, Task C independently determines the gate.

### B — narrow decision value: pass

Task B found no primary work measuring the exact recipient-state by batch-source
interaction with exact twins, a common verified reservoir, identity-disjoint
held-out work and the complete reciprocal 2x2 cancellation.

The residue is a causal-method measurement, not a new learning paradigm. Generic
autocurriculum, compositional generalization, verified self-training, learned
work reduction and own-state task selection are occupied. A bounded null would
still have decision value, but publication novelty alone does not justify a new
cell.

### C — cheapest decisive measurement: fail

Task C found no reusable load-bearing primitive after the required exclusions:
the finite carrier/verifier, learner/update, public-only selector, twin
acquisition, reciprocal isolation and held-out work counter are all new.

An estimator-only injected interaction can be checked in approximately 2–6
hours, but it cannot answer whether real acquired twins select meaningfully
different non-surface batches without leakage. The honest joint observation
requires the acquisition/selector stack plus the reciprocal harness, zero
control and injected positive control. Its conservative estimate is 24–80
focused hours.

Therefore the first valid number is the minimum experiment under another name.
The probe does not precede the harness; it is the harness. This is exactly the
IDEA_GATE design-circling alarm and exceeds the prospective eight-hour ceiling.

Task A's proposed forward-pass discordance check does not alter this result. No
E2 task family, verifier, learner, acquisition protocol or selector currently
exists, so obtaining the states and batches needed for that forward pass already
requires the load-bearing construction identified by Task C.
